✏ Описание

Я специализируюсь на создании и оптимизации текстовых запросов (промптов) для языковых моделей и систем искусственного интеллекта. Моя деятельность включает:

⦁ Разработку и оптимизацию промптов для широкого круга задач, включая генерацию текста и анализ данных
⦁ Создание чат-ботов и ИИ-ассистентов с использованием передовых моделей
⦁ Проектирование и внедрение RAG-архитектуры (Retrieval-Augmented Generation) для улучшения качества ответов
⦁ Работа с базами данных для эффективного хранения и обработки информации
⦁ Интеграцию ИИ-систем в приложения и бизнес-процессы
